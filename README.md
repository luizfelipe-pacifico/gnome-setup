# Meus scripts

Scripts e atalhos pessoais. Os arquivos reais ficam aqui; `~/.local/bin` e
`~/.local/share/applications` apontam para cá por links simbólicos.

- `bin/monitor-temp` — janela com temperatura, ventoinha, CPU, RAM e bateria
- `bin/projetos-git` — gerenciador visual dos projetos Git
- `bin/rpcs3-launch` — inicia o RPCS3 guardando logs de crash
- `bin/ds4-audio-mirror`, `bin/gamemode-profile` — utilitários de jogo
- `applications/` — atalhos do menu de aplicativos
